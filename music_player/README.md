# Keyboard Music Player

This application loads all WAV files from `music/sample_tracks` and controls
them with the keyboard.

## Controls

- `P` — play the selected track from the beginning
- `S` — stop
- `N` — next track
- `B` — previous track
- `Q` or `Esc` — quit

Run from the `Practice7` folder:

```bash
python music_player/main.py
```

You can add your own `.wav` files to the sample-tracks folder. They will be
loaded alphabetically the next time the application starts.
