# Practice 7: Pygame Games

This project contains three small Pygame applications:

1. **Mickey's Clock** — displays the current minutes and seconds with rotating hands.
2. **Music Player** — plays a small playlist with keyboard controls.
3. **Moving Ball** — moves a red ball with the arrow keys while keeping it on screen.

## Installation

```bash
pip install -r requirements.txt
```

## Running the applications

Run each command from the `Practice7` folder:

```bash
python mickeys_clock/main.py
python music_player/main.py
python moving_ball/main.py
```

Each application can be closed with the window close button. The music player
also supports `Q` or `Esc`, and the other applications support `Esc`.
